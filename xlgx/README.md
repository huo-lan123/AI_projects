# 熊了个熊

一款移动端优先、零依赖的单文件 HTML 消除小游戏，玩法对标《羊了个羊》。

## 简介

《熊了个熊》是一个纯前端小游戏：玩家点击未被遮挡的卡牌，将 3 张相同图案收入底部卡槽即可消除，清空全部卡牌即通关。项目全部逻辑（HTML + CSS + JavaScript）内联于单个 `index.html`，无框架、无打包工具、无第三方依赖，打开即玩，可直接静态托管。

## 特性

- **单文件零依赖**：整个游戏就是一个 `index.html`，可直接部署到任意静态托管平台。
- **两关模式**：第 1 关为轻松教程关，第 2 关为含盲盒与散牌的挑战关。
- **三种道具**：撤回 / 洗牌 / 移出（默认各 999 次，右上角显示剩余次数）。
- **真实堆叠手感**：基于层级 `zIndex` 与四角覆盖判定的卡牌遮挡逻辑。
- **程序化音频**：使用 Web Audio API 生成点击音效与背景音乐（C 大调五声音阶旋律 + 低音伴奏），背景音乐默认开启。
- **粉色梦幻主题**：粉紫渐变背景与立体卡牌样式，移动端自适应布局。
- **动态卡牌尺寸**：随场上卡牌减少自动放大并居中重排。

## 玩法

1. 点击未被遮挡（处于顶层）的卡牌，卡牌飞入底部 7 格卡槽。
2. 卡槽中相同图案集满 3 张即自动消除。
3. 清空场上全部卡牌即通关；底部卡槽被未消除卡牌填满则失败。
4. 善用道具与盲盒（背面显示「?」，点击揭示后飞入卡槽）。

## 技术栈

| 维度 | 方案 |
| --- | --- |
| 形态 | 单文件 HTML（内联 CSS / JS） |
| 渲染 | DOM 绝对定位 + zIndex 层级 + CSS 动画 |
| 音频 | Web Audio API（音效与 BGM 程序化生成） |
| 依赖 | 无框架、无打包工具、无第三方库 |

## 本地运行

直接用浏览器打开 `index.html` 即可游玩。

如需通过本地静态服务器运行：

```bash
# 使用 Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```

> 注意：受浏览器自动播放策略限制，背景音乐需用户首次点击「开始」后才会播放。

## 部署

由于是零依赖静态站点，可托管于任意静态平台（GitHub Pages、CloudStudio、Vercel、Netlify 等）。只需上传 `index.html` 这一个文件。

以 GitHub Pages 为例：将仓库推送到 GitHub 后在仓库 Settings → Pages 中选择对应分支与根目录 `/` 即可。
